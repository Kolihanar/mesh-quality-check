# 通用判断原则

## 严重程度等级

| 等级 | 含义 | 结论 |
|---|---|---|
| ⛔ 致命 | 负体积、翻转单元、面朝向错误、不封闭单元等拓扑/几何错误，或指标严重到求解器基本不可能稳定 | 不要开始计算，先修网格 |
| 🔴 高风险 | 指标超过求解器的报警阈值 | 很可能发散或精度明显下降，建议先处理；确实来不及时要配合保守的数值设置 |
| 🟡 中等 | 接近阈值，或通常可接受但需注意的情况（边界层大长宽比、少量凹单元） | 一般可以计算，关注收敛 |
| 🟢 可接受 | 未超出阈值 | 可以计算 |

总体结论取所有发现中最严重的等级。

## 影响范围

脚本把超标单元/面的占比分为三档：零星（<0.1%）、局部（<1%）、大面积（≥1%）。阈值在 `scripts/thresholds.json` 中可改。

解释时把**等级**和**范围**结合起来：

- 高风险 + 零星 + 远离关注区：通常可以先用保守设置试算，同时安排修复；
- 高风险 + 大面积，或位于壁面/界面/出口附近：应先修复；
- 中等 + 大面积：整体网格策略可能有问题（比如增长率过大、块划分不合理），值得重新审视。

## 位置比极值更重要

需要关注的位置：
- 壁面边界层：大长宽比通常是有意为之；高非正交性/歪斜度会直接影响壁面剪切和传热；
- 多相流界面经过的区域（VoF）：坏单元会放大界面伪速度和质量不守恒；
- 出口附近：坏单元容易引起回流和压力振荡；
- 远离边界的内部区域：常见于结构化分块的连接处或尺寸过渡区。

## 结合计算类型

| 计算类型 | 敏感程度 | 说明 |
|---|---|---|
| 稳态 RANS（单相） | 较低 | 少量零星坏单元通常可以接受 |
| 瞬态 URANS / 传热 | 中 | 坏单元会限制时间步 |
| 多相 VoF / 自由面 | 高 | 界面附近的非正交性和歪斜度影响很大 |
| LES / DNS | 高 | 对网格均匀性和正交性要求高 |
| 动网格 / FSI | 很高 | 初始网格的余量要大，运动后质量还会下降 |

## 不要做的事

- 不要把不同软件的同名指标数值放在一起比较；
- 不要根据一个最大值就宣布"网格不行"或"网格没问题"；
- 不要把网格质量合格说成网格无关。
